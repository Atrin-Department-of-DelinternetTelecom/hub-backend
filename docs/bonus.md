# What is the bonus?

Bonus is a way to add some extra features to a contract, for example, increasing bandwidth on internet contracts or SMS reward for cell contracts free or by cost.
Generally, each Bonus can attach to only `one type` of contract (cell, internet, etc.). on the other hand each contract can have a lot of Bonuses.

# Bonus types

Based on the provider, the system has two types of internal Bonuses and external service Bonuses. internal Bonuses that provides by the company (for example: `TARIFA PLANA FIXE RESIDENCIAL` on the Fix contracts) and the external Bonus provided by the external service provider (for example: `Aire Bonus` on mobile contracts).
Based on the action, some bonus needs technical action (for example: updating user data on radius) and some of them do not. Activating of Bonuses that relied on technical steps will be pending until the technical actions are done.

# Aire bono

Aire Bonuses are like an ordinary bonus but manages by the AIRE provider. Aire bonuses are imported by the `gfCellProviderFee` cron task from external APIs and stored in the `GfCellProviderFeeBonus` table.

# How does it work?

To attach a bonus to a contract, first, we should add bonuses to a fee group so any `contract` with those fee groups can have the related Bonuses (must add through the contract form manually).

# Attach bono process

When a bonus attached to a contract we will have the following situations:

1. bonus has `internetIpFix`:
   this type of bonus updates the internet section of contract by the bono static ip given from client form and also the `radiusProfileSufix` by the `M` value.
2. `needTechnicalAction` bonus
   this type of bonus set contract bonus state as `pendingActivation` and create an `installBono` event on the crm.
3. `affectRadius` bonus
   this type of bonus will update the user radius data to change speed (`internetMbIncluded`, `internetUpMbIncluded`) of contract. in this situation all of errored contract bonus will activate again.

**ATTENCTION**
when bonus was not under the situation 2 the bonus will activate if has not any radius error.
